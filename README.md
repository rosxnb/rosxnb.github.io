# ROSHAN BHARATI

Making the rosxnb context [online](https://rosxnb.github.io).

This space serves as my digital context —- a collection of notes, research findings, milestone projects,
and exploratory blogs. I'm building it to have a single, accessible place where I can revisit concepts,
recap quickly, and connect ideas over time.



## 🎯 My approach

My goal is to make topics intuitive by blending:

- **Theoretical foundations** — Clear explanations paired with mathematical formulations
- **Code snippets** — Practical implementations that bring theory to life
- **Visuals** — Diagrams and illustrations that aid understanding

While not every post will include all three elements, I plan to consistently pair theory with code simulations
whenever it helps deepen understanding.
